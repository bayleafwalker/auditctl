# P2.2 schema-runtime adoption boundary

This coordinator-owned migration changes auditctl's stateful central-schema
boundary and distribution contract together. The repository dispatch policy
already permits the touched `auditctl/`, `tests/`, `docs/`, `verification/`,
`.agents/`, `README.md`, and `pyproject.toml` paths. `uv.lock` is the generated
exact dependency lock required by the authorized 0.1.2 packaging change.

The immutable GitHub wheel for `vuoro-schema-runtime` 0.1.0 is used only for
pure `MigrationAsset`, UTF-8 SHA-256, contiguous migration validation,
identifier validation/quoting, schema SQL rendering, and migration-ledger
verdict plumbing. Auditctl retains its PostgreSQL runner, transaction and
advisory lock, ledger I/O and domain error messages, compatibility output and
reason strings, migration assets, DDL, role/grant policy, principal records,
and runtime-role rotation. Local SQLite and NDJSON modules are out of scope and
unchanged.
